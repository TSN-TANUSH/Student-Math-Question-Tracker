# 🎓 Student Math Question Tracker

A simple yet powerful tool that helps students organize, track, and revisit math questions efficiently.  
Built with a focus on usability, progress tracking, and learning consistency.

---

## 🧠 Features
- Add, edit, and delete math questions easily  
- Track solved and unsolved problems  
- Tag questions by difficulty or topic  
- Save progress locally or via cloud sync (optional)

---

## ⚙️ Tech Stack
- HTML5, CSS3, JavaScript  
- Node.js / Express (for backend if included)  
- JSON or MongoDB for data storage
